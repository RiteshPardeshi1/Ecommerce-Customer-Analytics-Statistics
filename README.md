# End-to-End Statistics Project: E-commerce Customer Analysis

A statistics-for-data-science project that analyses a simulated e-commerce customer population. Every step pairs the code with a plain-language insight, so the notebook reads like a guided lesson as well as an analysis.

## Project Questions

- What does a typical order look like?
- How spread out are order values?
- How are the variables related to each other?
- What can a sample tell us about the whole population?

## What It Covers

- Building a synthetic population of 1,000 visits, one variable at a time
- Descriptive statistics: mean, median, spread and distribution shape
- Visualising distributions with histograms and plots
- Correlation between variables
- Probability distributions and sampling with SciPy
- Hypothesis testing (t-test) and interpretation of results

## Tech Stack

Python, NumPy, Pandas, Matplotlib, Seaborn, SciPy, Jupyter Notebook

## Repository Contents

- `Ecommerce statistics project.ipynb`: the complete project notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install numpy pandas matplotlib seaborn scipy jupyter`
3. Run the cells in order with `jupyter notebook`. The data is generated inside the notebook, so no dataset download is needed.
